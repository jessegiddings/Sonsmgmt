# Vendored fonts

Both faces are variable fonts under the SIL Open Font License 1.1, self-hosted
rather than loaded from Google Fonts — no third-party request on page load, and
one file per family covers every weight the site uses.

| File | Family | Weights | Source |
| --- | --- | --- | --- |
| `big-shoulders-display-latin.woff2` | Big Shoulders Display | 400–800 | https://fonts.google.com/specimen/Big+Shoulders+Display |
| `archivo-latin.woff2` | Archivo | 100–900 | https://fonts.google.com/specimen/Archivo |

Both are latin subsets. Full OFL text: https://openfontlicense.org
